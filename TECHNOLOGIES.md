# Technologies

| Technologie | Rôle |
|---|---|
| React + TypeScript | Interface et typage |
| Vite | Développement et build |
| React Router | Navigation SPA |
| Leaflet + React Leaflet | Carte interactive |
| OpenStreetMap | Fonds cartographiques sans clé API |
| Lucide React | Icônes accessibles |
| localStorage | Persistance locale de démonstration |
| Vitest | Tests à ajouter/étendre |

Les formulaires sont structurés pour accueillir la validation React Hook Form + Zod lors de l’extension du prototype.
